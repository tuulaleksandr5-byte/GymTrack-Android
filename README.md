# GymTrack Android 💪

Тренировочный дневник для Android с тёмным дизайном и оранжевыми элементами. Работает офлайн: программа на Kotlin показывает встроенный сайт через локальный WebView.

## Возможности
- Тренировочные программы «Всё тело», «Верх тела», «Низ тела».
- Подходы, повторения, рабочий вес.
- Таймер отдыха 45/60/90/120 секунд.
- Календарь, история и график результатов.
- Воспроизведение собственных аудиофайлов.
- Сохранение занятий локально и экспорт/импорт JSON.

## Как получить APK
1. Открой вкладку **Actions** и workflow **Android APK**.
2. Дождись успешной автоматической сборки или нажми **Run workflow**.
3. Внутри успешного запуска прокрути до **Artifacts** и скачай **GymTrack-debug-apk**.
4. Распакуй ZIP и установи **app-debug.apk** на телефон Android 8+.

Это отладочная версия для тестирования, не подписанный релиз для Google Play.

## Сборка через Android Studio
Открой репозиторий как проект; необходимы JDK 17, Android SDK 35, Gradle 8.9.
Команда сборки: `gradle :app:assembleDebug`. APK появится в `app/build/outputs/apk/debug/`.

## Файлы
- `app/src/main/assets/index.html` — полноценное офлайн-приложение (HTML + CSS + JavaScript).
- `app/src/main/java/com/gymtrack/android/MainActivity.kt` — Android-оболочка, системный выбор музыки и экспорт JSON.
- `.github/workflows/android.yml` — автоматическая сборка APK.
- `scripts/check_assets.mjs` — статическая проверка сайта.

Данные хранятся только на устройстве. Перед удалением приложения сохрани резервную копию в JSON. После перезапуска аудиофайлы выбираются заново; фоновое воспроизведение с уведомлением пока не реализовано.
