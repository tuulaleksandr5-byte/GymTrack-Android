# GymTrack на Windows 💪

Это настоящая версия GymTrack для ПК с Windows 10 или 11 (x64).
Запускается отдельным окном **без браузера и без Android-эмулятора**.

## Скачать и установить

1. Открой вкладку GitHub **Actions**, выбери успешную сборку **Windows Desktop**.
2. В разделе **Artifacts** скачай архив `GymTrack-Windows`.
3. Распакуй ZIP; внутри будут:
   - `GymTrack-Setup-1.3.0.exe` — установщик Windows, создаёт ярлык рабочего стола.
   - `GymTrack-Portable-1.3.0.exe` — портативная версия, работает без установки.
4. Запусти нужный EXE.

Приложение пока не подписано коммерческим сертификатом. Windows может показать «Неизвестный издатель». Скачивай файл только из своего репозитория.

## Возможности

- Программы тренировок и сохранение выполненных подходов, повторений и веса.
- Таймер отдыха, календарь, история тренировок.
- Тёмный интерфейс, адаптированный к размеру окна.
- Все 12 GIF-анимаций для груди встроены в приложение и работают офлайн.
- Локальное воспроизведение собственных аудиофайлов, в том числе при свёрнутом окне, пока компьютер работает.
- Закладки YouTube и Spotify (без скачивания защищённых аудиодорожек).
- Резервные копии тренировок в JSON.

Данные сохраняются **локально на ПК**. Если ранее пользовался GymTrack в браузере или Android, импортируй резервную JSON-копию через раздел «Настройки» для переноса истории.

## Для разработчика

Из корня репозитория:
```powershell
cd desktop
npm install
npm start
```

Сборка установщика:
```powershell
npm run dist:win
```

Готовые EXE будут в `desktop/dist`. Приложение использует Electron и читает существующие ресурсы из `app/src/main/assets`, поэтому версии Android и Windows используют один интерфейс и те же GIF.

Офлайн-музыка в версии для ПК воспроизводится через встроенный HTML-аудиоплеер. Для воспроизведения после перезапуска программы музыкальные файлы нужно выбрать снова. Музыка останавливается при полном закрытии приложения или выключении ПК. Windows-версия пока не имеет отдельного системного фонового медиа-сервиса.

## Исправление чёрного экрана (1.1.1)

В ранней версии 1.1.0 Windows иногда показывала `ERR_UNEXPECTED (-9) loading gymtrack://app/index.html`. Исправлено: файлы интерфейса и GIF теперь читаются напрямую из локального пакета, без запроса к `file://` через Electron. Сборка проверяет загрузку главной страницы и анимаций.

Для обновления закрой старую версию GymTrack и установи 1.1.1 или запусти новый Portable EXE. Тренировки хранятся локально в данных приложения.

## Новое в 1.2.0: поиск трека из YouTube в SoundCloud

Открой **Музыка → Найти трек YouTube в SoundCloud**. Вставь ссылку на отдельное публичное видео YouTube (обычное видео, YouTube Music, Shorts) или напиши название песни и исполнителя, затем нажми **Поиск в SoundCloud**. Windows-версия умеет получать название публичного видео через YouTube oEmbed и открывать поиск по названию на SoundCloud в браузере.

Это поиск по метаданным, **не скачивание и не перенос музыки**. Не все песни YouTube присутствуют в SoundCloud; результаты нужно проверять вручную. Для распознавания URL YouTube необходим интернет. При недоступности YouTube можно ввести название песни вручную. В Android и браузерной версиях текстовый поиск работает; автоматическое получение названия видео реализовано пока только для Windows.

## 1.2.0 — поиск треков из YouTube на SoundCloud

В разделе «Музыка» вставь ссылку на видео YouTube в поле «Найти песню YouTube в SoundCloud». Нажми «Найти на SoundCloud», затем «Открыть результаты SoundCloud». GymTrack получает публичное название видео через YouTube oEmbed и открывает поисковую страницу SoundCloud в браузере. Если YouTube недоступен, введи название песни вручную.

Это поисковая функция, она не копирует и не скачивает защищённые треки и не гарантирует точного совпадения. Для показа результатов непосредственно внутри GymTrack потребовалась бы авторизация SoundCloud API.

## SoundCloud API — интеграция 1.3.0

Прямо в GymTrack для Windows: поиск реальных треков и публичных плейлистов через официальный SoundCloud API и прослушивание через официальный SoundCloud Widget в отдельном окне приложения.

**Для начала поиска нужен доступ SoundCloud API:** зарегистрируй своё приложение на https://developers.soundcloud.com/docs/api/register-app (на момент разработки SoundCloud требует Artist Pro для выдачи Client ID и Client Secret), затем открой **Музыка → Подключить SoundCloud API** и введи ключи там. Не отправляй их в чат и никогда не публикуй в GitHub. Приложение хранит ключи локально, в зашифрованном системном хранилище Windows (Electron safeStorage).

Если ключей пока нет, программы тренировок и музыка с компьютера работают без SoundCloud API. Поисковую ссылку на SoundCloud по названию трека можно использовать и без API.

Интеграция использует server-side OAuth **client_credentials** в главном процессе Electron: Access Token не предоставляется HTML-интерфейсу. Запросы `GET /tracks` и `GET /playlists` выполняются с `Authorization: OAuth TOKEN`. Встроенный плеер использует официальный `w.soundcloud.com/player/`. Данная функция не скачивает записи из SoundCloud, не обходит ограничения доступа и не гарантирует воспроизведение каждого трека.

Редактор программ доступен на Windows и Android в меню **Программы → Создать свою программу**. Можно создавать, редактировать, удалять, добавлять упражнения и переставлять их. Программы сохраняются локально и экспортируются в резервную копию JSON.
