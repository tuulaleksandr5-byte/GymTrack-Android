# GymTrack на Windows 💪

Это настоящая версия GymTrack для ПК с Windows 10 или 11 (x64).
Запускается отдельным окном **без браузера и без Android-эмулятора**.

## Скачать и установить

1. Открой вкладку GitHub **Actions**, выбери успешную сборку **Windows Desktop**.
2. В разделе **Artifacts** скачай архив `GymTrack-Windows`.
3. Распакуй ZIP; внутри будут:
   - `GymTrack-Setup-1.1.1.exe` — установщик Windows, создаёт ярлык рабочего стола.
   - `GymTrack-Portable-1.1.1.exe` — портативная версия, работает без установки.
4. Запусти нужный EXE.

Приложение пока не подписано коммерческим сертификатом. Windows может показать «Неизвестный издатель». Скачивай файл только из своего репозитория.

## Возможности

- Программы тренировок и сохранение выполненных подходов, повторений и веса.
- Таймер отдыха, календарь, история тренировок.
- Тёмный интерфейс, адаптированный к размеру окна.
- Все 12 GIF-анимаций для груди встроены в приложение и работают офлайн.
- Локальное воспроизведение собственных аудиофайлов, в том числе при свёрнутом окне, пока компьютер работает.
- Закладки YouTube и Spotify (без скачивания защищённых аудиодорожек).
- Резервные копии тренировок в JSON.

Данные сохраняются **локально на ПК**. Если ранее пользовался GymTrack в браузере или Android, импортируй резервную JSON-копию через раздел «Настройки» для переноса истории.

## Для разработчика

Из корня репозитория:
```powershell
cd desktop
npm install
npm start
```

Сборка установщика:
```powershell
npm run dist:win
```

Готовые EXE будут в `desktop/dist`. Приложение использует Electron и читает существующие ресурсы из `app/src/main/assets`, поэтому версии Android и Windows используют один интерфейс и те же GIF.

Офлайн-музыка в версии для ПК воспроизводится через встроенный HTML-аудиоплеер. Для воспроизведения после перезапуска программы музыкальные файлы нужно выбрать снова. Музыка останавливается при полном закрытии приложения или выключении ПК. Windows-версия пока не имеет отдельного системного фонового медиа-сервиса.

## Исправление чёрного экрана (1.1.1)

В ранней версии 1.1.0 Windows иногда показывала `ERR_UNEXPECTED (-9) loading gymtrack://app/index.html`. Исправлено: файлы интерфейса и GIF теперь читаются напрямую из локального пакета, без запроса к `file://` через Electron. Сборка проверяет загрузку главной страницы и анимаций.

Для обновления закрой старую версию GymTrack и установи 1.1.1 или запусти новый Portable EXE. Тренировки хранятся локально в данных приложения.
